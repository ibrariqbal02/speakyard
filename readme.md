# Speakyard

Practice speaking English with real people and AI: real-time chat, HD audio/video calls, group calls and AI practice calls.

- Web app: `frontend/speakyard-frontend/`
- API server: `backend/`
- Mobile (Capacitor): `mobile/` (on the `mobile` branch)

See [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) to set up and contribute, and [docs/PROJECT_PLAN.md](docs/PROJECT_PLAN.md) for the roadmap.
